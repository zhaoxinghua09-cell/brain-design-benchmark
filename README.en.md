This repository is an **Agent Skill package**: the core file `SKILL.md` follows the Agent Skills spec (YAML frontmatter) and turns "benchmark your AI brain design as a unified agent against the real human brain, neuroscience evidence and 2026 frontier AI" into a skill an AI agent can load directly.

---

## ✨ Features

- **Three-way benchmarking**: your design / the real human brain / 2026 frontier AI, scored on the same 12-dimension table (1–10).
- **Grounded Reference Method**: every judgment cites an external reference — neuroscience evidence or public frontier architecture. No claim without a source.
- **No absolute words**: "best / world-first" style unfalsifiable claims are banned; output is a verifiable three-tier gap triage.
- **12 dimensions**: memory layering, proactivity, tool use, self consistency, reflection/metacognition, planning (System 2), sleep-like consolidation, lifelong learning, safety governance, evaluation standardisation, energy/scalability, embodiment.
- **Gap triage + roadmap**: not just a score — tells you which dimensions lead by a generation, which are weak, and what to fix first.
- **Multilingual**: zh-CN, en, ja, ko, es, fr, de, ar.
